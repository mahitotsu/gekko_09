# toposort: toposort(deps)

`src/toposort.js` の `toposort(deps)` は、依存関係から実行順を決める。

- `deps` は `{ ノード: [そのノードが依存するノード, ...] }` の形。依存先は依存元より前に並ぶ。
- 値の配列にだけ現れるノードも結果に含める。
- 同時に実行可能なノードが複数あるときは、文字列として最も小さいもの（`<` 比較）を先にする。結果は入力のキーの順序に依存しない。

```js
toposort({ b: ['a'], c: ['a'], a: [] }) // ['a', 'b', 'c']
```

## 閉路

依存関係に閉路がある場合は `CycleError`（`src/toposort.js` から export、`name` は `'CycleError'`）を投げる。

- `error.cycle` は閉路を表す配列。先頭と末尾は同じノードで、隣り合うノード `X, Y` は「X が Y に依存する」を表す（例 `['a', 'b', 'c', 'a']` は a→b→c→a）。
- 閉路は、その閉路に含まれるノードのうち文字列として最も小さいものから始める。
- 自己依存 `{ a: ['a'] }` の `cycle` は `['a', 'a']`。
- 複数の閉路がある場合は、どれか一つを報告すればよい。
- `error.message` は `cycle: a -> b -> c -> a` の形式。
