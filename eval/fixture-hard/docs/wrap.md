# wrap: wrapText(text, width)

`src/wrap.js` の `wrapText(text, width)` は、文字列を表示幅 `width` 以内の行の配列に折り返す。

## 表示幅

各文字の幅は `src/width.js` の `charWidth(ch)`（全角 2、半角 1）で決まる。行の幅はその行の文字の幅の合計。

## 段落

- `\n` は強制改行。段落ごとに独立して折り返す。
- 空の段落は空文字列の行になる（`'ab\n\ncd'` → `['ab', '', 'cd']`）。

## 折り返し位置

段落を次の「字句」に分け、字句の境界でだけ改行する。

- 英単語: 半角の、空白以外の文字の連続（`Claude`, `v1.2`, `foo-bar`）。
- 全角文字: 1 文字ずつが一つの字句。
- 空白: 半角スペースの連続。

規則:

1. 先頭から貪欲に、行に収まる限り字句を詰める。
2. 行頭と行末の空白は出力しない（改行位置の空白は消える）。
3. 一つの英単語だけで `width` を超える場合は、その単語を `width` 文字ずつに分割する。
4. 英単語と全角文字の間（空白がなくても）は改行してよい。

## 禁則処理（追い出し方式）

- 行頭禁則文字: `、。，．・：；？！ー」』）】〉》ぁぃぅぇぉっゃゅょァィゥェォッャュョ`
  - 行頭に来てはいけない。改行の結果、次の行が行頭禁則文字で始まる場合は、現在の行の最後の字句を次の行へ追い出す。追い出したあとも次の行の先頭が行頭禁則文字なら、さらに追い出す（ただし現在の行が空になる場合は追い出さない）。
- 行末禁則文字: `「『（【〈《`
  - 行末に来てはいけない。行末がこれらの文字になる場合は、その文字を次の行へ追い出す（現在の行が空になる場合は追い出さない）。
- 追い出しで次の行が `width` を超えた場合、次の行もまた同じ規則で折り返す。

例（width = 6）:

- `'あいうえおかきくけこ'` → `['あいう', 'えおか', 'きくけ', 'こ']`
- `'あいう。えお'` → `['あい', 'う。え', 'お']`
- `'あい「うえ」お'` → `['あい', '「う', 'え」お']`
