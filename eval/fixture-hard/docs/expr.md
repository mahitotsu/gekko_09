# expr: evaluate(source, scope)

`src/expr.js` の `evaluate(source, scope = {})` は、数式の文字列を評価して数値を返す。`eval` / `Function` は使わないこと。

## 字句

- 数値: `12`, `3.5`, `.5`（指数表記はない）
- 識別子: `[A-Za-z_][A-Za-z0-9_]*`
- 演算子と記号: `+ - * / % ^ ( ) ,`
- 空白（スペース、タブ、改行）は読み飛ばす

## 構文と優先順位（低い順）

| 優先順位 | 演算子 | 結合 |
| --- | --- | --- |
| 1 | `+` `-`（二項） | 左 |
| 2 | `*` `/` `%` | 左 |
| 3 | `+` `-`（単項、前置） | 右（`--3` は 3） |
| 4 | `^`（べき乗） | 右 |
| 5 | 数値、変数、関数呼び出し、`( 式 )` | |

- `^` は単項マイナスより強く結びつく: `-2^2` は `-4`、`(-2)^2` は `4`。
- `^` の右辺には単項演算子を書ける: `2^-1` は `0.5`、`2^-2^2` は `2^(-(2^2))`。
- `2^3^2` は `2^(3^2)` = 512。
- 二項演算子の右辺にも単項演算子を書ける: `2*-3` は `-6`、`1--1` は `2`。

## 変数と関数

- 変数は `scope` から読む。ない場合は `ReferenceError`、メッセージは `unknown variable: <名前>`。
- 関数は `min(a, ...)`, `max(a, ...)`（引数1個以上）, `abs(a)`（引数ちょうど1個）。
  - 引数の数が合わない場合は `TypeError`。
  - 未知の関数は `ReferenceError`、メッセージは `unknown function: <名前>`。
  - 識別子の直後に `(` が来たら関数呼び出し。識別子と `(` の間に空白があってもよい。

## エラー

- `/` と `%` の右辺が 0 のときは `RangeError`、メッセージは `division by zero`。
- 構文エラーは `SyntaxError`。メッセージに `at <位置>` を含める。位置は問題のある字句の先頭の 0 始まりの文字位置。入力の途中で終わった場合は入力の長さ（末尾の位置）。
  - `1 +` → `at 3`
  - `2 * (3` → `at 6`
  - `1 $ 2` → `at 2`（使えない文字）
  - `1 2` → `at 2`（余分な字句）
  - `()` → `at 1`
