# 採点基準: クーポンの併用ルールの仕様（docs/coupon-spec.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。

- V1: 併用の可否を決めている（全部可、種類ごと、1枚だけ、など）
- V2: 枚数の上限を決めている（上限なしと決める場合も、その理由を書く）
- V3: 割引を適用する順序を決めている（登録順、割引率の大きい順など）
- V4: 今の実装（割合を順に掛け合わせる）との関係に触れている
- V5: 同じコードを2回使ったときの扱いを決めている
- V6: 端数（四捨五入、税込みの切り捨て）が順序によって変わることに触れている
- V7: 決めたルールのテストのケースを具体的に挙げている
