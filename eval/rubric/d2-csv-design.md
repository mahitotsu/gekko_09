# 採点基準: CSV の RFC 4180 対応の設計（docs/csv-design.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。

- V1: ダブルクォートで囲まれたフィールドの中のカンマを、区切りとして扱わない
- V2: クォートの中の `""` を、1つのダブルクォートとして扱う
- V3: クォートの中の改行を、行の区切りとして扱わない
- V4: 改行コード CRLF を扱う
- V5: 末尾の改行の有無で、空の行が増えない
- V6: 閉じていないクォートなど、不正な入力の扱い（エラーにするなど）を決めている
- V7: 今の parseCsv の動作（クォートのない入力）を変えないこと、または既存の呼び出し元への影響に触れている
- V8: 1文字ずつ状態を持って読む方法など、実装の方針が具体的に書かれている
- V9: テストのケースを具体的に挙げている
