# 採点基準: Cart の利用ガイド（docs/cart-guide.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。

- V1: 公開メソッド（add、remove、count、applyCoupon、subtotal、total、receipt）の使い方が書かれている
- V2: total の計算の順序（小計 → クーポンを順に割引 → 四捨五入 → 税込み）が正しく書かれている
- V3: クーポンは割合（%）で、複数枚は順に掛け合わさる（合計の割合の足し算ではない）ことが書かれている
- V4: 商品の上限（MAX_CART_ITEMS、50）と、超えたときの例外 'cart is full' が書かれている
- V5: add で上限を超えて例外になっても、その行の数量が増えたまま残る（先に qty を足してから検査している）ことに触れている
- V6: 税込みの計算が addTax で切り捨てになっていること（コメントの「四捨五入」と食い違う）に触れている
- V7: receipt は今は合計だけで、明細は出ないこと（TODO）に触れている
