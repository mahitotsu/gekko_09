# 採点基準: テスト（test/ 以下）

テストのコードを読み、次の観点を確かめるテストがあれば 1、なければ 0 とする。テストが通るかどうかは別に機械で確かめる。

- T1: 期限の境界（60日と 61日）
- T2: 利用日が提出日より後の明細
- T3: 領収書の境界（999円と 1,000円）、または日当に領収書が要らないこと
- T4: 宿泊費の上限（泊数を掛ける、または上限ちょうど）
- T5: 宿泊費の改定の前日と当日（9月30日と 10月1日）
- T6: 日当の日帰りの半額、または申請額が規程の額より少ない場合
- T7: 会議費の 1人 5,000円ちょうどと超え
- T8: 物品の境界（99,999円と 100,000円）
- T9: 承認経路の 5万円の境界、または接待費で部長以上が加わること
- T10: 承認経路の 30万円の境界、または役員の申請が経理課長になること
- T11: 支払日の土曜・日曜の調整
- T12: 入力データの不整合で終了コード 2 になり、出力がないこと
- T13: CLI を実際に実行して出力ファイルを確かめるテストがある
