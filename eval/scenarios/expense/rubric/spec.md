# 採点基準: 最終の仕様書（docs/spec.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。

- S1: コマンドの形式と終了コード、対象の申請（提出日が対象月）
- S2: 入力ファイル3つの列（明細の数・種別の意味を含む）
- S3: 出力ファイル3つの列と並び順
- S4: 明細の判定の順とコード（E01〜E04、W01〜W03）
- S5: 宿泊費と日当の上限（改定を含む）
- S6: 会議費から接待費への区分の変更
- S7: 申請の状態の決め方
- S8: 承認経路の規則（承認額で判定、役員の申請、経路なしの場合）
- S9: 支払と支払日の規則
- S10: 入力データの不整合の扱い
- S11: 置き換わった旧仕様や見送りの要望を、現行の仕様として書いていない
