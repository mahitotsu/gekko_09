# 採点基準: 要件（docs/requirements.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。表現は問わない。

- R1: コマンドの形式（`--month`、`--data`、`--out`）と終了コード（0、1、2）、提出日が対象月の申請を審査すること
- R2: 期限は 60日で、提出日 − 利用日 が 60日を超えると却下（60日ちょうどは期限内）、第1回の 90日から変更された
- R3: 利用日が提出日より後の明細は却下
- R4: 領収書は 1,000円以上で必要（日当は不要）、第1回の 3,000円から変更された
- R5: 物品は 10万円以上なら却下
- R6: 宿泊費の上限は役職・地域別で泊数を掛け、超えた分は減額（却下しない）、第1回の一律 10,000円から変更された
- R7: 宿泊費の上限は宿泊日で選び、2026-10-01 以降の宿泊は東京の一般 12,000円・主任 13,000円（課長以上は変えない）
- R8: 日当は役職の日額（一般 2,000〜役員 5,000）× 日数、日帰りは半額、規程の額が上限で申請額が少なければ申請額
- R9: 会議費は1人あたり 5,000円を超えると接待費に区分を改める（5,000円ちょうどは会議費）
- R10: 判定の順（日付、期限、領収書、物品、宿泊費、日当、会議費）と、最初に当てはまったもの1つを結果・コードにすること
- R11: 申請の状態（却下・一部承認・承認）の決め方
- R12: 承認経路: 上長、5万円以上か接待費を含むなら部長以上、30万円以上なら役員、役員の申請は経理課長（ACCT）
- R13: 承認の金額は承認額（却下・減額の後）で判定し、承認額 0 円の申請には経路を付けない
- R14: 却下された会議費は区分を改めず、承認経路の判定に使わない
- R15: 支払日は翌月25日で、土曜・日曜なら直前の金曜日（祝日は考えない）
- R16: 入力データの不整合では何も出力せず終了コード 2、全行を調べ、問題の行の番号を示す
- R17: 見送りの要望（海外出張、距離からの交通費の計算、仮払い、宿泊費と日当の相殺、祝日の調整）を、実装しないものとして区別している
- R18: 置き換わった旧仕様（期限 90日、領収書 3,000円、宿泊費一律 10,000円、日当一律 3,000円、承認は上長1人だけ）を、現行の要件として書いていない
