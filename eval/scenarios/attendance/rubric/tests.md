# 採点基準: テスト（test/ 以下）

テストのコードを読み、次の観点を確かめるテストがあれば 1、なければ 0 とする。テストが通るかどうかは別に機械で確かめる。

- T1: 丸めの境界（出勤の切り上げ、退勤の切り捨て）
- T2: 休憩の境界（6時間ちょうどと6時間15分、または8時間ちょうどと8時間15分）
- T3: 深夜の境界（22:00 または 5:00）、または日をまたぐ打刻
- T4: 日の種類（日曜・土曜・会社休日のいずれか）
- T5: 1日8時間を超える法定外
- T6: 週40時間を超える法定外（前月にまたがる週、または日の分を重ねないこと）
- T7: 法定休日の労働が法定外に数えられないこと
- T8: 月60時間の境界（ちょうどと超え）
- T9: 60時間超の適用月（2026年9月分以前は25%のまま）、または月ごとの累計のやり直し
- T10: 割増の単価の四捨五入（0.5円）
- T11: 金額が月の合計に対して切り捨てられること
- T12: 残業の注意の境界（2700分または4800分）
- T13: 入力データの不整合で終了コード 2 になり、出力がないこと
- T14: CLI を実際に実行して出力ファイルを確かめるテストがある
