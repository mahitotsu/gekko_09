# 採点基準: 最終の仕様書（docs/spec.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。

- S1: コマンドの形式と終了コード、対象の打刻（日付が対象月）
- S2: 入力ファイル3つの列（出勤・退勤の時刻の形式、退勤が出勤より前なら翌日、を含む）
- S3: 出力ファイル3つの列と並び順
- S4: 丸めと休憩の規則（拘束時間、4時間後から取る）
- S5: 日の種類の判定
- S6: 法定外の判定（1日8時間、週40時間、法定休日の扱い）
- S7: 60時間超の判定と適用月
- S8: 深夜の判定
- S9: 賃金の計算と端数処理
- S10: 注意の一覧の規則
- S11: 入力データの不整合の扱い
- S12: 置き換わった旧仕様や見送りの要望を、現行の仕様として書いていない
