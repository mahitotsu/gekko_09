# 採点基準: 要件（docs/requirements.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。表現は問わない。

- R1: コマンドの形式（`--month`、`--data`、`--out`）と終了コード（0、1、2）、日付が対象月の打刻を集計すること
- R2: 打刻は15分単位に丸める（出勤は切り上げ、退勤は切り捨て）、第1回の1分単位から変更された
- R3: 休憩は拘束時間（丸めた後）が6時間を超えれば45分、8時間を超えれば60分（ちょうどは超えない）、第1回の一律60分から変更された
- R4: 休憩は丸めた出勤の4時間後から取ったものとして扱う（深夜の判定に使う）
- R5: 日曜は法定休日、土曜と会社休日は所定休日（日曜と会社休日が重なれば法定休日）、日の種類は出勤した日で決める
- R6: 法定休日の労働は実働の全体を35%割り増し、法定外にも週の累計にも数えない
- R7: 1日8時間を超えた分と、週（月曜〜日曜）40時間を超えた分が法定外で25%。日の法定外は週で重ねて数えず、週は月をまたいで前月の日も累計に含める
- R8: 深夜は22:00〜翌5:00で25%、他の割増と重なれば足す（休憩の分は含まない）
- R9: 月60時間を超えた法定外は50%（25%に代えて）、月の初日から累計し、2026年10月分から適用（9月分以前は25%のまま）
- R10: 割増の1時間あたりの額は円未満を四捨五入（0.5は切り上げ）、金額は月の合計の分に対して円未満切り捨て（日ごとではない）、基本の賃金も月の合計に対して切り捨て
- R11: 日をまたぐ打刻（退勤が出勤より前の時刻なら翌日）の扱いと、丸めの結果が逆転した打刻は実働0分でエラーにしないこと
- R12: 残業の注意の一覧（法定外が2700分を超えれば45H超、4800分を超えれば80H超）
- R13: 打刻のない日・社員は出力しないこと、対象月の外の打刻は出力しないこと
- R14: 入力データの不整合では何も出力せず終了コード2、全行を調べ、問題の行の番号を示す
- R15: 変更の経緯として、どの回で何が変わったかを書いている（第2回〜第4回）
- R16: 見送りの要望（30分丸め、打刻の自己修正、代休・振替休日、変形労働時間制、日ごとの端数処理、深夜を6時まで、休憩を実働で判定、法定休日を日曜に固定しない）を、実装しないものとして区別している
- R17: 置き換わった旧仕様（1分単位、休憩一律60分、残業は1日8時間超だけ、深夜と休日は手計算、日ごとの端数切り捨て）を、現行の要件として書いていない
