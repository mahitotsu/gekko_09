# 採点基準: 設計（docs/design.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。

- D1: 入出力と集計の規則を分けたモジュール構成になっている
- D2: 入力データの検証を、出力ファイルを書く前に行う流れになっている
- D3: 打刻の丸め（出勤切り上げ・退勤切り捨て）と、日をまたぐ退勤の扱いが書かれている
- D4: 休憩を、丸めた拘束時間で決め、出勤の4時間後から取ったものとして深夜の判定に反映する方法が書かれている
- D5: 日の種類（法定休日・所定休日・平日）の判定が書かれている（曜日の求め方がタイムゾーンなどの影響を受けない）
- D6: 週40時間の判定が、月曜はじまりの週で、日の法定外を重ねず、法定休日を除き、前月の日を含む方法として書かれている
- D7: 月60時間超の判定が、月ごとに累計をやり直し、適用月（2026年10月分から）を考慮する方法として書かれている
- D8: 深夜の分を、実際の時刻（22:00〜翌5:00）と休憩の除外で数える方法が書かれている
- D9: 賃金の計算で、割増の単価の四捨五入と、月の合計に対する切り捨てが書かれている（整数で計算する）
- D10: 社員ごとの処理と、出力の並び順（社員番号、日付の順）が書かれている
- D11: 打刻のない社員・日を出力しないこと、対象月の外の打刻を出力に含めないことが書かれている
- D12: エラー処理で、引数の誤り（1）と入力データの不整合（2）を区別している
- D13: テストの方針として、境界値を挙げている
- D14: 要件（最終の決定）と矛盾する記述がない
