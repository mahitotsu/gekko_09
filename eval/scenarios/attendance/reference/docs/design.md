# 勤怠集計システム 設計

要件: docs/requirements.md。外部パッケージなし、Node.js 24、ES モジュール。

## 1. モジュール構成

| ファイル | 役割 |
| --- | --- |
| `src/cli.js` | 引数の解析と検証、3つの入力の読み込みと検証、社員ごとの集計の呼び出し、出力 |
| `src/attendance.js` | 集計の規則（丸め、休憩、日の種類、法定外、60時間超、深夜、賃金、注意）。入出力を持たない純粋な関数 |
| `src/csv.js` | CSV の読み書き（クォートなし、見出し行あり、出力は LF） |

## 2. データの流れ

1. 引数を検証する（足りない、`--month` が `YYYY-MM` でない → 終了コード 1）。
2. 3つの CSV を読み、全行を検証する（連携仕様書 3.1）。最初の不整合で、社員番号か日付を含むメッセージを出して終了コード 2。出力の前に調べるので、ファイルは作られない。
3. 社員を社員番号の昇順に処理する。社員ごとに、その社員の全打刻（対象月の前後を含む）を日付の順に `analyze` し、結果から対象月の日だけを残す。
4. 対象月の日がある社員だけ、月の合計（`monthly`）と注意（`alertLevel`）を求める。
5. 出力ディレクトリを作り、3つの CSV を書く。

## 3. 集計の手順（attendance.js）

- `measure(in, out)`: 出勤・退勤を分に直し（退勤が出勤より前の時刻なら 1440 を足す）、出勤を切り上げ・退勤を切り捨てる。拘束時間から休憩を決め、丸めた出勤から退勤までの1分ごとに、休憩の分（出勤+240 から休憩の長さ）を除いて実働を数え、時刻（1440 で割った余り）が 22:00 以降か 5:00 前なら深夜に数える。
- `breakMinutes(span)`: 480 を超えれば 60、360 を超えれば 45。
- `dayType(date, holidays)`: 曜日は UTC の日付から求める（タイムゾーンの影響を受けない）。日曜、土曜・会社休日の順に調べる。
- `analyze(punches, holidays)`: 日付順に1日ずつ処理する。週の番号（月曜はじまり）が変わったら週の累計を 0 に、月が変わったら月の累計を 0 にする。法定休日は実働のすべてを法定休日の分にして累計に入れない。それ以外は法定内 = min(実働, 480)、週の法定外 = 週の累計 + 法定内 − 2400 を 0〜法定内に収めた値、法定外 = (実働 − 法定内) + 週の法定外。月が 2026-10 以降なら、月の累計 + 法定外 − 3600 を 0〜法定外に収めた値が60時間超。
- `premiumUnit(rate, pct)` と `pay(unit, minutes)`: 割増の単価は整数の演算 `floor((rate × pct + 50) / 100)`、金額は `floor(単価 × 分 / 60)`。小数の誤差を避けるため、すべて整数で計算する。
- `monthly(employee, days)`: 日ごとの結果を合計し、基本と4つの割増を求める。法定外の割増は 60時間超を除いた分、60時間超の割増は 50% の単価。
- `alertLevel(overtime)`: 4800 を超えれば 80H超、2700 を超えれば 45H超。

## 4. エラー処理

| 状況 | 動作 |
| --- | --- |
| 引数が足りない、`--month` の形式が不正、未知の引数 | 標準エラーに理由、終了コード 1 |
| 入力データの不整合 | 標準エラーに社員番号か日付、終了コード 2、出力なし |

## 5. テスト方針

- `attendance.js` の関数を単体で試す（丸めの境界、休憩の 360/375/480/495分、深夜の 22:00 と 5:00 と休憩の重なり、日の種類、週40時間と前月の日、60時間の累計の境界と月の区切りと適用月、割増の単価の四捨五入と月合計の切り捨て、注意の境界）。
- CLI をサンプルデータで実行し、連携仕様書の例と比べる。入力データの不整合で終了コード 2 になり、出力がないことを確かめる。
