# 勤怠集計システム 要件

根拠: 議事録（第1回 2026-06-12、第2回 2026-07-17、第3回 2026-08-28、第4回 2026-09-18）、就業規程（2026-10-01 改定）、連携仕様書 第4版。第3回で仕様が確定し、第4回の変更管理会議で変更が承認された。連携仕様書 第4版を正とする。

## 1. 目的と範囲

- 社員マスタ・打刻・会社休日の CSV から、指定した月の勤怠を就業規程どおりに集計し、日ごとの結果、月ごとの賃金の内訳、残業の注意の一覧を出すコマンドラインツール。対象は時給制の従業員。
- 範囲外: 代休・振替休日の扱い、変形労働時間制（第3回）、打刻の自己修正（第2回）。

## 2. 機能要件

### 2.1 コマンド

- `node src/cli.js --month YYYY-MM --data <入力> --out <出力>`。Node.js 24 以降、外部パッケージなし。終了コード: 0 成功、1 引数の誤り、2 入力データの不整合。
- 日付が対象月の打刻を集計する。ただし週の累計には、前月の同じ週の日の打刻も使う。

### 2.2 丸めと実働（第2回 決定1・2、第4回 変更2・6）

1. 出勤を15分単位に切り上げ、退勤を15分単位に切り捨てる。退勤が出勤より前の時刻なら翌日の退勤（第3回 決定5）。
2. 拘束時間 = 丸めた退勤 − 丸めた出勤（負なら 0。逆転した打刻は実働 0 分でエラーにしない）。
3. 休憩は丸めた拘束時間で決める: 360分を超えれば 45分、480分を超えれば 60分（ちょうどは超えない）。丸めた出勤の240分後から取ったものとして扱う。
4. 実働 = 拘束時間 − 休憩。

### 2.3 日の種類（第2回 決定3）

- 日曜は法定休日。土曜と会社休日（holidays.csv）は所定休日。日曜と会社休日が重なれば法定休日。それ以外は平日。出勤した日で決める（第4回 変更5）。

### 2.4 法定外と60時間超（第2回 決定4・5、第3回 決定1・3、第4回 変更1・3・4）

- 法定休日の労働は、実働のすべてを法定休日の分とし、法定外にも週・月の累計にも入れない。
- 平日と所定休日: 1日 8時間までを法定内、超えた分を法定外とする。さらに、週（月曜〜日曜）の法定内の累計が40時間を超えた分も法定外とする（日の法定外は重ねて数えない。前月の日を含む）。
- 月の法定外（日の分と週の分）を、月の初日から日付の順に累計し、60時間を超えた分が60時間超。2026年10月分から適用し、9月分以前は 0（月は打刻の日付の月）。

### 2.5 深夜（第3回 決定2）

- 実際の時刻で 22:00〜翌5:00 の実働の分。休憩の分は含まない。

### 2.6 賃金（第3回 決定2・3・4）

- 基本 = 時給 × 実働の分 ÷ 60。割増は、法定外（60時間超を除く）25%、60時間超 50%（25%に代えて）、法定休日 35%、深夜 25%。重なる割増は足す。
- 割増の1時間あたりの額 = 時給 × 率を円未満で四捨五入（0.5 は切り上げ）。各金額は月の合計の分に対して、1時間あたりの額 × 分 ÷ 60 を円未満切り捨て（日ごとには切り捨てない）。

### 2.7 注意の一覧（第3回 決定6）

- 月の法定外が 2700分を超えたら `45H超`、4800分を超えたら `80H超`（どちらか一方）。

### 2.8 出力と入力の検証（第3回 決定7、第4回 確認事項）

- daily_results.csv、monthly_results.csv、alerts.csv。列・並び順・書式は連携仕様書 第4版 4章・7章のとおり。打刻のない日・社員の行は出さない。
- 入力データの不整合（社員番号の重複、時給が正の整数でない、打刻の社員がいない・日付や時刻が不正・出勤と退勤が同じ・同じ日が2行、会社休日の日付が不正）は、全行を調べ、問題の行の番号を含むメッセージを出し、何も出力せず終了コード 2。

## 4. 見送りの要望

- 30分単位の丸め（第2回）、従業員による打刻の修正（第2回）。
- 代休・振替休日、変形労働時間制（第3回）。
- 日ごとの金額を切り上げて足す案、深夜を翌6時までとする案（第3回）。
- 休憩の判定を実働で行う案、法定休日を日曜に固定しない案（第4回）。
