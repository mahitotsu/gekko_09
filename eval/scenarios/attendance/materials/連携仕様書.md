# 勤怠集計システム 連携仕様書

第4版（2026年9月18日）　情報システム課

第3版からの変更（変更管理会議 2026年9月18日）: 60時間超の割増の適用月、休憩の判定（拘束時間）、週40時間の判定、60時間の累計、日をまたぐ打刻、丸めの結果が逆転した打刻の扱いを明記。

## 1. 概要

社員マスタ・打刻・会社休日の CSV を読み、指定した月の勤怠を就業規程（2026年10月1日改定）と議事録（第2回〜第4回）の決定に従って集計し、日ごとの結果、月ごとの賃金の内訳、残業の注意の一覧の CSV を出力するコマンドである。

## 2. 実行環境

- Node.js 24 以降。外部のパッケージは使わない。
- 入口のファイルは `src/cli.js` とする。

## 3. コマンド

```
node src/cli.js --month <対象月> --data <入力ディレクトリ> --out <出力ディレクトリ>
```

| 引数 | 内容 |
| --- | --- |
| `--month` | 対象月。`YYYY-MM` の形式。日付がこの月の打刻を集計する |
| `--data` | 入力ディレクトリ。`employees.csv`、`punches.csv`、`holidays.csv` を置く |
| `--out` | 出力ディレクトリ。なければ作る。`daily_results.csv`、`monthly_results.csv`、`alerts.csv` を書く |

終了コード: 0 成功、1 引数の誤り（標準エラーに理由）、2 入力データの不整合（3.1。出力ファイルは作らない。標準エラーに、問題の行を示す番号を含める）。

### 3.1 入力データの不整合

対象月以外の行も含め、すべての行を調べる。最初に見つかった不整合で終了する。

| 対象 | 不整合 | メッセージに含める番号 |
| --- | --- | --- |
| 社員 | 社員番号が重複している／時給が1以上の整数でない | 社員番号 |
| 会社休日 | 日付が実在する `YYYY-MM-DD` でない | 日付 |
| 打刻 | 社員が社員マスタにない／日付が実在する `YYYY-MM-DD` でない／出勤か退勤が `HH:MM`（00:00〜23:59）でない／出勤と退勤が同じ時刻／同じ社員の同じ日付が2行ある | 社員番号 |

## 4. ファイルの形式

UTF-8（BOM なし）、1行目は見出し、区切りはカンマ、クォートなし（フィールドにカンマ・改行・ダブルクォートは含まれない）。出力の改行は LF で、最後の行の後にも改行を置く。金額は整数（桁区切りなし）、時間は分の整数、日付は `YYYY-MM-DD`、時刻は `HH:MM`。

## 5. 入力

### 5.1 employees.csv（社員マスタ）

| 列 | 内容 |
| --- | --- |
| employee_id | 社員番号 |
| name | 氏名 |
| hourly_rate | 時給（円） |
| department | 部署名 |

### 5.2 punches.csv（打刻）

| 列 | 内容 |

| out | 退勤の時刻（`HH:MM`）。出勤より前の時刻なら翌日の退勤 |

### 5.3 holidays.csv（会社休日）

| 列 | 内容 |

## 6. 集計

打刻の1行（1日分）ごとに、社員ごとの日付の順に次の順で求める。

### 6.1 丸めと実働

1. 出勤を15分単位に切り上げ、退勤を15分単位に切り捨てる（退勤が出勤より前の時刻なら、翌日として先に24時間を足してから丸める）。
2. 拘束時間 = 丸めた退勤 − 丸めた出勤（負なら 0）。
3. 休憩（分）: 拘束時間が 480分を超えれば 60、360分を超えれば 45、それ以外は 0。休憩は丸めた出勤の240分後から、休憩の長さの分だけ取ったものとして扱う。
4. 実働（work_min）= 拘束時間 − 休憩。
5. 深夜（night_min）= 実働のうち、22:00〜翌5:00 に当たる分（実際の時刻。休憩の分は含まない）。

### 6.2 日の種類

日曜は `法定休日`、土曜と holidays.csv の日付は `所定休日`、それ以外は `平日`（日曜は会社休日と重なっても `法定休日`）。出勤した日で決める。

### 6.3 法定外（overtime_min）と法定休日（holiday_min）

- 法定休日: 実働のすべてを holiday_min とする。overtime_min は 0。週と60時間の累計には入れない。
- 平日・所定休日:
  - 法定内 = min(実働, 480)。
  - 週の法定外 = 週（月曜〜日曜）のその日までの法定内の累計が 2400 を超えた分（その日の法定内を超えない範囲）。前日までの累計には前月の日も含める。
  - overtime_min = (実働 − 法定内) + 週の法定外。
  - 60時間超（over60_min）: 打刻の日付の月が `2026-10` 以降なら、月の初日からの overtime_min の累計が 3600 を超えた分（その日の overtime_min を超えない範囲）。それより前の月は 0。

### 6.4 月ごとの集計

社員ごとに、対象月の日ごとの結果を合計する。割増の1時間あたりの額 = 時給 × 割増率（%）÷ 100 を、円未満で四捨五入する（0.5 は切り上げ）。

| 列 | 計算 |
| --- | --- |
| base_pay | 時給 × work_min ÷ 60（円未満切り捨て） |
| overtime_pay | 割増25%の額 × (overtime_min − over60_min) ÷ 60（円未満切り捨て） |
| over60_pay | 割増50%の額 × over60_min ÷ 60（円未満切り捨て） |
| night_pay | 割増25%の額 × night_min ÷ 60（円未満切り捨て） |
| holiday_pay | 割増35%の額 × holiday_min ÷ 60（円未満切り捨て） |
| total_pay | 上の5つの合計 |

### 6.5 注意の一覧

月の overtime_min が 4800 を超えれば `80H超`、2700 を超えれば `45H超`（どちらでもなければ出さない）。

## 7. 出力

### 7.1 daily_results.csv（日ごとの結果）

対象月の打刻がある日だけ。社員番号の昇順、その中で日付の昇順。

| 列 | 内容 |
| --- | --- |
| employee_id | 社員番号 |
| date | 日付 |
| day_type | `平日`、`所定休日`、`法定休日` |
| clock_in | 丸めた出勤の時刻（`HH:MM`） |
| clock_out | 丸めた退勤の時刻（`HH:MM`。翌日にかかるときも `HH:MM`） |
| break_min | 休憩（分） |
| work_min | 実働（分） |
| overtime_min | 法定外（分） |
| over60_min | うち60時間超（分） |
| night_min | 深夜（分） |
| holiday_min | 法定休日の労働（分） |

### 7.2 monthly_results.csv（月ごとの結果）

対象月の打刻がある社員だけ。社員番号の昇順。

| 列 | 内容 |
| --- | --- |
| employee_id | 社員番号 |
| name | 氏名 |
| work_min | 実働の合計（分） |
| overtime_min | 法定外の合計（分。over60_min を含む） |
| over60_min | 60時間超の合計（分） |
| night_min | 深夜の合計（分） |
| holiday_min | 法定休日の労働の合計（分） |
| hourly_rate | 時給 |
| base_pay | 基本の賃金 |
| overtime_pay | 法定外の割増 |
| over60_pay | 60時間超の割増 |
| night_pay | 深夜の割増 |
| holiday_pay | 法定休日の割増 |
| total_pay | 合計 |

### 7.3 alerts.csv（注意の一覧）

社員番号の昇順。注意がなければ見出しだけ。

| 列 | 内容 |
| --- | --- |
| employee_id | 社員番号 |
| name | 氏名 |
| overtime_min | 法定外の合計（分） |
| level | `45H超`、`80H超` |
