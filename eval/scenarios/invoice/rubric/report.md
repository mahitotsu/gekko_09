# 採点基準: 報告書（docs/report.md）

採点のときには、報告書に加えて、作業ディレクトリで実行した `npm test` の結果（合否とテストの数）を渡す。各項目を、満たしていれば 1、満たしていなければ 0 とする。

- P1: 第2回の要件の変更（締め日、送料無料の基準、消費税の端数処理、特約店の割引のうち3つ以上）への対応を書いている
- P2: 第3回で追加された仕様（数量割引、送料の行、取消の除外、入力の不整合のうち3つ以上）への対応を書いている
- P3: 第4回の変更（価格改定、返品、繰越、発行の条件、マイナスの税額のうち3つ以上）への対応を書いている
- P4: テストの内容（何を確かめたか）を具体的に書いている
- P5: テストの結果を、件数や合否として具体的に書いている
- P6: テストの結果の記述が、渡された `npm test` の結果と矛盾しない
- P7: 残っている課題や、範囲外とした事項（見送りの要望など）を書いている
- P8: 実装していないことを実装したと書いていない（報告書の主張が、仕様書や渡された結果と矛盾しない）
