# 採点基準: 最終の仕様書（docs/spec.md）

各項目を、文書に書かれていれば 1、書かれていない・誤っていれば 0 とする。

- S1: コマンドの形式と終了コード
- S2: 入力ファイル6つ（顧客、商品、受注、返品、入金、前回請求額）の列
- S3: 出力ファイル2つの列（請求書の繰越の列と、明細の種類・日付の列を含む）
- S4: 出力の並び順（請求書と明細。同じ日付の注文と返品の順を含む）
- S5: 請求期間の規則（末日締めと日付締め）
- S6: 単価・数量割引・送料の規則（価格改定の適用、特約店 10%、100個以上 5%、10,000円以上で送料無料、地域別の送料）
- S7: 返品の規則（按分と切り捨て、返品日の期間に計上、送料は返金しない）
- S8: 消費税の規則（請求書ごと・税率ごとに1回、端数処理の3方法と空欄、マイナスの場合）
- S9: 繰越の規則と、請求書を発行しない条件
- S10: 入力データの不整合の扱い（返品・入金・前回請求額を含む）
- S11: 置き換わった旧仕様や見送りの要望を、現行の仕様として書いていない
