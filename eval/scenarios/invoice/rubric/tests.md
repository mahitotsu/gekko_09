# 採点基準: テスト（test/ 以下）

テストのコードを読み、次の観点を確かめるテストがあれば 1、なければ 0 とする。テストが通るかどうかは別に機械で確かめるので、ここでは観点の有無だけを見る。

- T1: 日付締めの請求期間の境界（締め日当日と翌日、前月の締め日と翌日）
- T2: 末日締め、または年をまたぐ1月分、またはうるう年の2月の請求期間
- T3: 送料無料の境界（9,999円と 10,000円、またはそれに相当する境界）
- T4: 数量割引の境界（99個と 100個）
- T5: 特約店の単価の1円未満切り捨て
- T6: 端数処理の3つの方法（切り捨て・四捨五入・切り上げ）と空欄、四捨五入でちょうど 0.5円になる場合
- T7: 価格改定の適用開始日の前日と当日
- T8: 返品の金額の按分と切り捨て、または数量割引のかかった明細の返品
- T9: 返品を返品日の期間に計上すること（前の期間の注文の返品、または期間外の返品）
- T10: 金額がマイナスになる場合の消費税
- T11: 繰越（前回の請求額と期間内の入金）、または注文がなくても前回の請求額か入金があれば発行すること
- T12: 取消の注文を含めないこと、または請求書を発行しない条件
- T13: 入力データの不整合で終了コード 2 になり、出力がないこと（返品の不整合を含む）
- T14: 引数の誤りで終了コード 1 になること
- T15: CLI を実際に実行して出力ファイルを確かめるテストがある
