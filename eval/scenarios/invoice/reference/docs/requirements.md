# 請求書発行システム 要件

根拠: 議事録（第1回 2026-06-04、第2回 2026-07-09、第3回 2026-08-20、第4回 2026-09-03）、請求業務規程（2026-09-01 改定）、連携仕様書 第4版。第3回で仕様が確定し、第4回の変更管理会議で変更が承認された。連携仕様書 第4版を正とする。

## 1. 目的と範囲

- 受注データ・返品データ・入金データ・前回請求額データ・顧客マスタ・商品マスタの CSV から、対象月の請求書と請求明細の CSV を作るコマンドラインツール。
- 範囲外: PDF の出力（第3回で次期に見送り）。

## 2. 機能要件

### 2.1 コマンド

- `node src/cli.js --month YYYY-MM --data <入力> --out <出力>`（連携仕様書 3章）。Node.js 24 以降、外部パッケージなし。
- 終了コード: 0 成功、1 引数の誤り、2 入力データの不整合。

### 2.2 請求の単位と期間

- 顧客ごと、請求期間ごとに1通。請求書番号は `YYYYMM-顧客コード`（規程 第2条）。
- 締め日は顧客ごとに 1〜28日 または末日（第2回 決定1、規程 第3条）。
- 請求期間（規程 第4条）: 末日締めは対象月の1日〜末日。日付締めは前月の締め日の翌日〜対象月の締め日（1月分は前年12月から）。期間の初日と末日を含む。
- 対象は、状態が「確定」で注文日が請求期間内の注文（第3回 決定3）。
- 請求期間内に注文も返品もなく、前回の請求額も入金もない顧客には請求書を発行しない（第4回 決定4。第3回 決定4「注文がない顧客には発行しない」を改めた）。

### 2.3 金額

- 単価は、注文日の時点で有効な商品マスタの行（適用開始日が注文日以前でもっとも新しい行）の税抜単価。税率と商品名も同じ行のもの（第4回 決定1、規程 第5条）。
- 特約店は単価の 90%、1円未満切り捨て（第2回 決定5、規程 第5条）。
- 明細の金額 = 単価 × 数量。数量が 100 以上の明細は 5% の数量割引、割引額は1円未満切り捨て。特約店は割引後の単価で計算した金額に割り引く（第3回 決定1）。

### 2.4 送料

- 注文ごと。注文の商品の金額（税抜、数量割引の後、8% の商品も含む）の合計が 10,000 円以上なら無料（第2回 決定2）。
- 無料でなければ、配送地域の送料: A 800円、B 1,000円、C 1,500円（規程 別表）。
- 送料は 10% 課税で 10% の金額に含め、請求明細に `SHIPPING`／`送料` の行として出す。無料の注文には送料の行を出さない（第3回 決定2）。

### 2.5 消費税

- 税率は商品マスタ（10% または 8%）、送料は 10%。
- 請求書ごとに、税率ごとの金額の合計に税率を掛け、税率ごとに1回だけ端数処理する（第2回 決定3、規程 第7条）。
- 端数処理は顧客マスタの方法（切り捨て・四捨五入・切り上げ）、空欄は切り捨て（第2回 決定4）。四捨五入は 0.5円以上を切り上げ。

### 2.6 返品

- 返品は、返品日が含まれる請求期間の請求書に、マイナスの金額の行として載せる。元の注文の期間は問わない（第4回 決定2、規程 第8条）。
- 金額 = 元の明細の金額（特約店の割引・数量割引の後）× 返品数量 ÷ 元の数量、1円未満切り捨て、マイナス。単価・税率・商品名は元の明細（元の注文日の価格）のもの。
- 送料は返金しない。元の注文の送料無料の判定も変えない。

### 2.7 前回の請求額と入金（繰越）

- 前回の請求額 = 前回請求額データの前月分の行（なければ 0）。2か月以上前の行は使わない（第4回 確認事項）。
- 入金額 = 入金日が請求期間内の入金の合計（締め日の考え方は注文と同じ）。
- 繰越額 = 前回の請求額 − 入金額（マイナスもありうる）。今回の請求額 = 繰越額 + 今回の請求金額（税込）（第4回 決定3、規程 第9条）。

### 2.8 金額がマイナスの場合の消費税

- 税率ごとの合計がマイナスなら、絶対値で税額を求めて端数処理し、マイナスの符号を付ける（第4回 決定5、規程 第7条4項）。

### 2.9 入力データの不整合

- 次のどれかが1行でもあれば、何も出力せず終了コード 2。対象期間外や取消の注文も含めて全行を調べ、問題の行の番号（注文番号・返品番号・入金番号・顧客コード）をメッセージに含める（第3回 決定5、第4回 決定1・2、連携仕様書 3.1）。
  - 受注: 顧客がマスタにない、商品がマスタにない、注文日の時点で有効な価格がない
  - 返品: 注文がない、その注文にその商品がない、取消された注文、返品数量の合計が注文数量を超える
  - 入金・前回請求額: 顧客がマスタにない

### 2.10 出力

- invoices.csv と invoice_lines.csv。列、並び順、書式は連携仕様書 第4版 4章・6章のとおり。明細は日付順で、同じ日付では注文が先、返品が後。

## 3. 変更の経緯

| 項目 | 第1回（現行の手作業） | 変更後 | 変更した回 |
| --- | --- | --- | --- |
| 締め日 | すべて末日 | 顧客ごとに 1〜28日 または末日 | 第2回 |
| 送料無料の基準 | 5,000円以上 | 10,000円以上（注文ごと、税抜） | 第2回 |
| 消費税の端数処理 | 明細ごとに切り捨て | 請求書ごと・税率ごとに1回、方法は顧客ごと | 第2回 |
| 特約店の割引 | 5% | 10%（単価に適用、1円未満切り捨て） | 第2回 |
| 数量割引 | なし | 100個以上で 5% | 第3回 |
| 送料の扱い | 未定 | 10% 課税、明細に送料の行 | 第3回 |
| 取消の注文 | 紛れ込むことがある | 対象外 | 第3回 |
| 価格 | 商品ごとに1つ | 適用開始日ごと（注文日の時点で有効なもの） | 第4回 |
| 返品 | なし | 返品日の期間にマイナスで計上 | 第4回 |
| 繰越 | なし | 前回の請求額 − 入金額を繰り越す | 第4回 |
| 請求書を発行しない条件 | 注文がない顧客（第3回） | 注文・返品・前回の請求額・入金がどれもない顧客 | 第4回 |

## 4. 見送りの要望

- 税込・税抜の表示を得意先ごとに選ぶ（第1回の要望、第2回で見送り。インボイス制度で税抜金額と税額を載せるため）。
- 請求書の PDF 出力（第3回で次期に見送り）。
- 重量による送料（第3回で見送り。商品マスタに重量がない）。
- 返品のときに送料も返金する（第4回で見送り）。
- 入金を請求書ごとに消し込む（第4回で見送り。顧客ごとの差額の繰越だけ）。
- 返品を元の注文の請求期間にさかのぼって修正する（第4回で見送り。返品日の期間に計上）。
