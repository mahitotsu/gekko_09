# 請求書発行システム 設計

要件: docs/requirements.md。外部パッケージなし、Node.js 24、ES モジュール。

## 1. モジュール構成

| ファイル | 役割 |
| --- | --- |
| `src/cli.js` | 引数の解析と検証、6つの入力の読み込みと検証、顧客ごとの処理の呼び出し、出力 |
| `src/billing.js` | 計算（請求期間、有効な価格、単価、明細の金額、返品の金額、送料、消費税、繰越、1顧客分の請求書）。入出力を持たない純粋な関数 |
| `src/csv.js` | CSV の読み書き（クォートなし、見出し行あり、出力は LF） |

## 2. データの流れ

1. `cli.js` が引数を検証する（足りない、`--month` が `YYYY-MM` でない → 終了コード 1）。
2. 6つの CSV を読む。商品マスタは商品コードごとに行の配列にまとめる（価格改定で複数行ある）。
3. 全行を検証する（連携仕様書 3.1）。最初の不整合で、行の番号を含むメッセージを出して終了コード 2。出力の前に調べるので、ファイルは作られない。
   - 受注: 顧客・商品の存在、注文日の時点で有効な価格の存在
   - 返品: 注文の存在、その注文の明細に商品があるか、注文が確定か、明細ごとの返品数量の累計が注文数量以下か（返品データの行の順に累計し、超えた行の番号を示す）
   - 入金・前回請求額: 顧客の存在
4. 顧客コードの昇順に `invoiceFor` を呼び、請求書と明細を集める。`null` の顧客は飛ばす。
5. 出力ディレクトリを作り、2つの CSV を書く。

## 3. 計算の手順（billing.js）

- `billingPeriod(month, closingDay)`: 末日締めは対象月の1日〜末日（末日は `Date.UTC(y, m, 0)`）。日付締めは前月（1月なら前年12月）の締め日の翌日〜対象月の締め日。翌日は暦の上で求める（前月が平年の2月で28日締めなら、翌日は3月1日）。
- `priceRowAt(rows, date)`: 適用開始日が `date` 以前の行のうち、適用開始日がもっとも新しい行（入力の順に依存しない）。
- `unitPriceFor(customer, row)`: 特約店は `floor(単価 × 90 / 100)`。
- `lineAmount(unitPrice, quantity)`: `単価 × 数量`。数量 100 以上なら `金額 − floor(金額 × 5 / 100)`。
- `originalLine(customer, orderRow, products)`: 注文日の価格の行から、単価・金額・税率・商品名を求める。注文の明細と、返品の元の明細の両方に使う。
- `returnAmount(original, quantity)`: `−floor(元の金額 × 返品数量 / 元の数量)`。
- `tax(amount, rate, rounding)`: `amount × rate` を 100 で割った商と余りで丸める（浮動小数点を使わない）。四捨五入は余り 50 以上で切り上げ、切り上げは余りがあれば切り上げ、それ以外は切り捨て。`amount` がマイナスなら `−tax(−amount, …)`。
- `invoiceFor(month, customer, data)`:
  1. 状態が確定で、注文日が期間内の顧客の注文を、注文番号ごとにまとめる。
  2. 元の注文がこの顧客のもので、返品日が期間内の返品を選ぶ。
  3. 前回の請求額（前月分の行、なければ 0）と、入金日が期間内の入金の合計を求める。
  4. 注文も返品もなく、前回の請求額も入金も 0 なら `null`。
  5. 注文ごとに明細の金額を合計し、10,000 未満なら地域の送料の行を最後に足す（返品は判定に関係しない）。返品は元の明細から金額を求め、マイナスの行にする。
  6. 明細を (日付, 種類: 注文=0・返品=1, 注文番号または返品番号) で並べる。
  7. 10% の合計（送料・返品を含む）と 8% の合計から税額を求め、今回の請求金額、繰越額（前回 − 入金）、今回の請求額（繰越 + 今回）を求める。

## 4. エラー処理

| 状況 | 動作 |
| --- | --- |
| 引数が足りない、`--month` の形式が不正、未知の引数 | 標準エラーに理由、終了コード 1 |
| 入力データの不整合（2章の3） | 標準エラーに行の番号、終了コード 2、出力なし |

## 5. テスト方針

- `billing.js` の関数を単体で試す（締め期間の境界、年またぎ、うるう年、価格改定の前日と当日、特約店の単価、数量割引の 99/100、送料の 9,999/10,000、返品の切り捨て、端数処理の各方法と 0.5 円、マイナスの税額、繰越、発行しない条件）。
- CLI をサンプルデータで実行し、連携仕様書の例と比べる。入力データの不整合の各場合で終了コード 2 になり、出力がないことを確かめる。
