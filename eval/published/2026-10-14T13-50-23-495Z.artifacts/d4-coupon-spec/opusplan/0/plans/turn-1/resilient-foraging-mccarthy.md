# 計画: docs/coupon-spec.md（クーポン複数枚利用ルールのたたき台）

## Context
カートでクーポンを複数枚使ったときのルール（併用可否・枚数上限・適用順序）を決めるための仕様たたき台を書く。実装はしない（src/ や test/ は変更しない）。成果物は `docs/coupon-spec.md` の1ファイルのみ（docs/ は新規作成）。

## 根拠にする現状コード（文書の「現状」節に書く）
- `src/cart.js:27-30` `applyCoupon(code, percent)` — クーポンは「小計に対する%割引」の1種類だけ。検証なしで配列に追加。
- `src/cart.js:39-43` `total()` — 追加順に `amount *= (1 - percent/100)` を掛け合わせ（複利的）、最後に1回 `Math.round`、その後 `addTax`。つまり **割引は税抜小計に適用 → 税計算**。
- 現状の問題点（仕様で塞ぐもの）: 同じコードを何度でも追加できる／枚数上限なし／percent が 100 超・負でも通る（合計が負になりうる）／定額クーポンの概念がない。
- `src/money.js:8-10` `addTax` はコメントで「四捨五入」と書きつつ実装は `Math.floor`。端数処理の節で「未解決の食い違い」として記載するだけで、どちらが正かはこの文書では決めない（税の仕様の問題なので要確認に回す）。
- `src/config.js` に `TAX_RATE`, `MAX_CART_ITEMS` がある → 上限枚数も同様に設定値（例 `MAX_COUPONS_PER_ORDER`）とする案として書く。

## 文書の構成と各節の要点
1. **目的と範囲** — 対象は1注文（1カート）内の複数クーポン。対象外: クーポン発行・有効期限管理・ユーザーごとの利用回数（別仕様）。
2. **現状** — 上記コードの挙動と問題点を箇条書き。
3. **用語** — 定率クーポン（%）、定額クーポン（円）、小計（税抜）、割引後小計、合計（税込）。定額は現状なしだが、併用ルールを決める上で避けられないので「導入する場合の案」として扱う。
4. **ルール案**（各項目に「案」「理由」「代替案」を書く）
   - 4.1 併用可否: 同一コードの重複は不可。定率は1枚まで、定額は1枚まで、定率＋定額の併用は可。→ 定率どうしの「加算か乗算か」問題を回避できるのが理由。代替案: 定率同士も乗算で許可（現状の挙動）。
   - 4.2 枚数上限: 1注文 2枚（= 4.1 の帰結）。設定値として持つ。
   - 4.3 適用順序: 追加順に依存させない。**定額 → 定率** の順（店舗側に有利、例で差額を示す: 小計10,000円・500円引・10%引 → 8,550円 vs 定率先 8,500円）。代替案: 定率→定額（顧客に有利）。
   - 4.4 税との関係: 割引は税抜小計に適用し、その後に税を計算（現状維持）。
   - 4.5 端数処理: 各段階で円未満を処理する（案: 割引額を切り捨て＝顧客不利にならない方向は要議論）。現状は最後に1回丸め。`addTax` のコメントと実装の食い違いを明記。
   - 4.6 下限: 割引後小計は 0 円未満にしない。定率は 1〜100 の整数のみ受け付ける。
5. **漏れやすい観点**（エラー・境界）
   - 上限超過・重複・併用不可のときの挙動（追加を拒否しエラーを返す／既存を置き換える、のどちらか → 案は拒否）とエラーメッセージ。
   - 最低購入金額つきクーポンを想定する場合、商品削除で条件を割ったときに自動で外すか。
   - クーポンの取り消し（removeCoupon）が必要か。
   - レシート表示: 各クーポンの割引額を行として出す（`receipt()` の TODO と関連）。
6. **計算例** — 3〜4例（クーポンなし／定率のみ／定額のみ／併用）を税込合計まで表で示す。数値は手計算で検算する。
7. **未決事項（要確認）** — 定額クーポンを導入するか、適用順序、端数処理の方向、`addTax` の丸め方、上限を超えたときの挙動。

## 書き方の方針
- 日本語。「たたき台」なので各ルールは断定せず「案」とし、理由と代替案を併記する。
- 現状コードとの差分（挙動が変わる点）を各ルールに一言添える。

## 確かめ方
- 計算例の数値を手計算で再確認（例: 10,000 −500 = 9,500 → ×0.9 = 8,550 → 税10% → 9,405）。
- src/・test/ に変更がないこと。docs/coupon-spec.md のみ作成されていること。
